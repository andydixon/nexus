# Alchementary Link

**A desktop client for SSH, Telnet, RAW TCP, VNC, GitHub, local terminals, and Leviathan binary analysis — with secure credential handling and a focused, multi-session workflow.**

Alchementary Link helps you manage many connections at once, keep terminal work organised, and move files with confidence.

## Highlights

- SSH, Telnet, RAW TCP, VNC, GitHub, and local terminal sessions in one app
- Tabbed sessions with split panes, pinning, and reordering
- SFTP browser with drag-and-drop uploads and a directory picker
- Leviathan binary workbench with hex editing, entropy, carving, BinSnoop, structure parsers, transforms, and spectrogram tools
- Disconnected overlay with one-click reconnect
- Broadcast input, snippets, and terminal search
- Session recording and playback
- Secure credential storage with OS keychain and encrypted vault fallback

## Quick start

1. Launch Alchementary Link.
2. Click **New** in the sidebar and create a connection profile.
3. Click **Connect** to open a session in a new tab.

Prefer a one-off session? Use **Cmd+Shift+Q** / **Ctrl+Shift+Q** to quick connect.

If a session drops, use the **Reconnect** button in the disconnected overlay.

## Keyboard shortcuts

All shortcuts use **Cmd** on macOS and **Ctrl** on Windows/Linux.

| macOS Shortcut    | Windows/Linux Shortcut | Action                      |
| ----------------- | ---------------------- | --------------------------- |
| Cmd + K           | Ctrl + K               | Open command palette        |
| Cmd + N           | Ctrl + N               | New connection              |
| Cmd + W           | Ctrl + W               | Close current tab           |
| Cmd + Tab         | Ctrl + Tab             | Next tab                    |
| Cmd + Shift + Tab | Ctrl + Shift + Tab     | Previous tab                |
| Cmd + 1–9         | Ctrl + 1–9             | Switch to tab by number     |
| Cmd + ,           | Ctrl + ,               | Open settings               |
| Cmd + F           | Ctrl + F               | Find in terminal            |
| Cmd + Shift + D   | Ctrl + Shift + D       | Split pane vertically       |
| Cmd + Shift + E   | Ctrl + Shift + E       | Split pane horizontally     |
| Cmd + Shift + R   | Ctrl + Shift + R       | Toggle session recording    |
| Cmd + Shift + B   | Ctrl + Shift + B       | Toggle broadcast input mode |
| Cmd + Shift + S   | Ctrl + Shift + S       | Open snippet library        |
| Cmd + Shift + Q   | Ctrl + Shift + Q       | Quick connect               |
| F11               | F11                    | Toggle fullscreen           |
